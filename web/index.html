导入模型

目标 ≤ 200,000 顶点 · 单文件 ≤ 18 MB

02

选择对应点

0 对

先将两侧人脸放大并转到正面。使用灰模渲染检测，无需 UV；先预览建议，再采用或手动修正。已有贴合结果时先恢复原始模板。

尚未自动检测

    按住 Shift 点击模板，再点击目标的相同部位。至少 3 对不共线的点。点击列表中的模板点或目标点可重选，点对右侧可删除。

    1. 尚未选择对应点

    曲线对应

    新增后 Shift + 点击两侧模型，依次绘制同一部位；每侧至少 2 个节点。按网格表面折线连接，非平滑样条。节点编号表示方向；过粗网格请减少采样数。已有结果请先恢复原始模板。

    曲线点采用后才参与求解。修改曲线后请重新生成并采用；采用前保留旧点对。

    03

    区域排除

    模板 0 面 · 目标 0 面

    Shift + 点击模型，红色为排除区域。模板区域在整体对齐后固定；目标区域不参与贴合。对应点所在面不可排除。

    04

    贴合与导出

    多阶段先减少形变自由度与匹配采样，最后全顶点精修；保留拓扑和 UV。小模型会跳过不必要的粗层。

    精确三角面匹配 · 法线过滤 · 防翻面已启用。夹角越小越严格，两侧面朝向需一致。

    保留顶点顺序、面和 UV。需要配套贴图时，请使用下方“导出纹理模型 · ZIP”。

    05

    笔刷修正

    蓝色 0% 保护 → 金色 100% 完全影响；红色为硬锁定。绘制值决定目标权重，沿用上方半径和强度；权重影响手动笔刷和纹理细化。

    完成贴合后，选择笔刷并在左侧拖动。

    左键拖动修正，Alt + 左键旋转，右键平移，Esc 取消当前笔画。对应点与排除区锁定；半径按目标尺寸计。投射最远为笔刷半径，沿用贴合法线夹角，跳过目标排除区。修改后需重新烘焙贴图。

    06

    纹理与烘焙

    每侧一张贴图，需完整 OBJ UV。输入图 ≤ 8 MB、16 百万像素。先贴合，再烘焙扫描颜色到模板 UV。

    距离按目标包围盒对角线计；使用上方的法线夹角。未匹配和排除区保持透明；模板 UV 需不重叠、位于 0–1。

    尚未烘焙

    07

    网格诊断与清理

    检测并高亮非流形边、无效面、孤立点及绕序冲突。普通导入失败的文件也可单独检查。先预览，再选择是否应用修复。

    08

    纹理辅助贴合

    先完成几何贴合，左侧调到正面；两侧需完整 UV 和同一人物、相近光照的贴图。模板贴图应来自中性表情，不使用当前目标的烘焙图作匹配。

    自动生成共用正交视图，沿用对应点、排除区、软权重和防翻面。0% 权重顶点固定；位移按目标尺寸计。

    未进行纹理细化。预览采用前，原结果与烘焙贴图保留；采用后需重新烘焙。

    09

    批处理与序列

    尚未选择扫描。

    同拓扑模式核对顶点数量及面索引顺序；顶点编号仍须对应相同部位。不同拓扑扫描需先各自建立点对，再导出并加载约束 JSON。

    约束按扫描文件名匹配，并核对模板拓扑。

    修复会自动开启检测和烘焙。使用前后原本正常的帧插值，再按本帧点对、固定区和软权重重新贴合；修复后重新检查，合格才烘焙。缺少前后参考、异常段过长或检查失败时继续隔离。原扫描及原异常缓存保留，修复不消除扫描本身的噪声或恢复缺失纹理。

    启用后先收集序列，再比较扫描粗糙度、离面误差和局部不连贯跳变。未修复的可疑帧保留已有几何和约束，跳过平滑/烘焙并切断历史；报告列出原因。边界、短片段或不同扫描拓扑可能上下文不足；检测不能可靠区分所有大幅噪声与真实运动，需复查。

    自适应时，上方强度作为上限。先补偿姿态，再按局部表情速度降低强度；达到阈值的区域停止平滑，保留快速峰值。阈值以目标尺寸百分比/相邻帧计，越低越早保护运动。大幅扫描噪声也可能被当作运动，仍需检查结果。

    用于连续、等间隔的同一人物序列，按文件名数字顺序处理。双向先收集贴合/光流结果，再结合相邻前后帧；片段首尾保留原几何，至少 3 帧才有可平滑的中间帧。先补偿姿态与尺度，保留本帧硬点、排除区、软权重和防翻面约束，最后烘焙。失败切断片段；强平滑可能削弱快速表情峰值，请为片段切换另建批次。

    双向收集阶段取消：完成已收集前缀的平滑/烘焙。平滑阶段取消：完成当前帧，剩余帧保留未平滑几何并跳过烘焙。

    使用第 06 节加载的模板参考贴图；请先将左侧模型转到正面。共用第 08 节光流参数、当前左侧相机朝向和软权重；几何与光流独立求解，启用时序后再跨帧平滑。

    启用光流后自动开启烘焙。无法验证纹理改善的帧记为失败，保留几何并跳过烘焙，继续下一帧。遮挡、嘴内或光照差异仍需人工检查。

    未选择贴图。

    按主名匹配（scan01.obj → scan01.png），每个扫描一张贴图；同名多图视为歧义。共用第 06 节的分辨率、边缘扩展、投射距离及当前法线夹角。模板和扫描均需有效 UV；烘焙失败保留几何并继续。

    尚未启动批处理。

      每批最多 50 项，单 OBJ ≤ 18 MB，单贴图 ≤ 8 MB / 16 百万像素，上传及未压缩输出各 ≤ 256 MB。按文件名数字顺序求解；勾选烘焙后导出各项 OBJ、MTL、PNG 和报告。建议启动前保存工程；关闭页面后后台继续，本地服务停止则中断。
