# Face landmark model

Official MediaPipe Face Landmarker bundle, downloaded for local CPU inference.

- [Model documentation](https://developers.google.com/edge/mediapipe/solutions/vision/face_landmarker)
- [Official download](https://storage.googleapis.com/mediapipe-models/face_landmarker/face_landmarker/float16/latest/face_landmarker.task)
- Bytes: 3,758,596
- SHA-256: `64184e229b263107bc2b804c6625db1341ff2bb731874b0bcc2fe6544e0bc9ff`

`python setup_landmarks.py` downloads only if explicitly run and validates the above digest before replacing the file. The app does not make network requests for detection. See the upstream documentation and model cards for model details.
