# Mesh Wave 现有功能检查（2026-11-11）

本轮只修复现有功能，没有新增产品功能。以 `6400f24` 为检查起点。

## 发现并修复

| 范围 | 问题与影响 | 修复 |
| --- | --- | --- |
| 连续表面对应点 | 用约束 Gram 矩阵判秩会平方条件数；两个很近但独立的有效点可能被丢弃，随后误报约束冲突 | 对约束转置直接做带主元 QR，只展开有效列，保留真实冗余／冲突检查 |
| OBJ 导出 | 10 位有效数字在大世界坐标下丢失细节，测试中三角面退化 | 使用可往返双精度的 17 位有效数字；保留原面、UV、顶点顺序 |
| 求解性能与计时 | 连续点／权重求解重复执行初始和最终整网格最近面查询；总时间漏计最终法线查询 | 复用查询结果，最后的质量查询完成后再记录总时间；每个模型的对应点检查复用包围盒尺度 |
| 批处理稳定性 | 工作线程启动失败时，内存显示失败，磁盘却仍显示运行中；重启后被误标为中断 | 保存失败原因和终止状态，标记未执行项、生成报告、清理未启动线程并释放求解锁；磁盘本身故障时保留原始错误 |
| 笔刷显示与拾取 | 修改几何后使用旧包围盒；随动排除面的颜色覆盖层停在旧坐标 | 失效旧包围盒，并同步覆盖层坐标及包围体；撤销／重做一同还原 |
| 接口输入稳定性 | JSON 数组、字符串或 null 被当成内部异常，返回 500 | 明确检查请求为对象，返回 400；补齐英文错误文案 |

## 性能对照

同机合成有 UV 网格，三阶段、8 次总迭代、整数与连续表面硬约束；每种网格在优化前后交替运行各 3 次，取墙钟耗时中位数。对照复用相同的约束求解模块，以隔离冗余距离查询的影响；不是全版本、全功能的统一性能评分。测试产物在被 Git 忽略的 `output/audit-benchmark.json`。

| 顶点／三角面 | 查询优化前 | 查询优化后 | 耗时减少 | 两组输出最大顶点差 |
| --- | --- | --- | --- | --- |
| 2,401 / 4,608 | 2.15 秒 | 1.92 秒 | 10.7% | 0 |
| 10,201 / 20,000 | 14.13 秒 | 12.66 秒 | 10.4% | 0 |

这两个样例最终平均表面距离分别为 6.37e-6、1.21e-6 个 OBJ 单位；硬点最大误差低于 5e-17，最小参考投影面积比分别约 0.905、0.791。它们用于验证数值约束、防翻面和优化没有改变结果，不代表真实人脸或语义对应的精度。

## 尚未验证的范围
